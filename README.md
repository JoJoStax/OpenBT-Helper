# OpenBT-Helper
App designed to support OpenHID-BT app by capturing from your phone the bluetooth packets and sends them as reports to be captured allowing all of us! User and Dev to implement this for all BT devices.


## How it works
Through enabling the correct android Debug options in the android developer options. **guided by the app** 
The user is able to capture one by one all the **features** they love to use on there headphones or other devices,
on capture an overlay will be enable to select what feature you are trying to use, lets say for example:

- Using gamemode, switching modes.
- Changing pre-set EQ
- Changing the ANC mode

## How this will help

The user also gives basic contact through there github user, to automatically send us the report created,
from our side ill manually implement the calls or analising them to implement a feature , while also being assisted by AI agents when stuck.

From your side by the end you can participate in testing your device patch, to be able to complete the process.

**By the end we should be able to get a device running**
